📖 生成后：三步免费上线

  1. 下载得到 index.html
  2. 到下面任一个免费托管平台注册并上传（三选一）：
    • Cloudflare Pages：dash.cloudflare.com → Workers & Pages → 创建 → Upload assets → 拖入 index.html → 部署
    • Netlify：app.netlify.com/drop → 把 index.html 拖进页面
    • GitHub Pages：GitHub 新建仓库 → 上传 index.html → Settings→Pages→分支 main → Save（详细步骤和怎么拿网址：看下面「GitHub Pages 详细步骤」）
  3. 拿到网址，发到 QQ 群，完成 🎉
📄 GitHub Pages 详细步骤（含怎么获取网址，点开查看）
  1. 注册 / 登录 GitHub：打开 github.com 注册（免费），登录后点右上角 ＋ → New repository； 名字填英文（如 mc-server-site），选择 Public（公开），其余默认 → 点 Create repository
  2. 上传文件：在新仓库页面点 Add file → Upload files，把生成好的 index.html 拖进虚线框（或点 choose your files 选择），再点绿色 Commit changes 上传完成
  3. 开启 Pages：点仓库页上方的 Settings（齿轮图标）→ 左侧菜单往下找 Pages → 在 "Build and deployment" 里：Source 选 Deploy from a branch → Branch 选 main，目录保持 /(root) → 点 Save
  4. 等待 1~3 分钟，让 GitHub 自动构建你的网站（此时去喝口水）
  5. 获取网址（两种办法）：
    • 办法一：回到 Settings → Pages，等页面顶部出现绿色横幅： Your site is live at https://你的用户名.github.io/仓库名/ —— 这行网址就是你的网站地址，点它即可打开，把它发给玩家就行！
    • 办法二：点仓库顶部 Actions 标签，找到 pages build and deployment 这个任务， 等它变成绿色 ✓ 后点进去，顶部同样能看到网址
  6. 打不开怎么办：① 确认网址里的"仓库名"和你建仓库时填的名字一致； ② 确认 index.html 在仓库根目录（不要在子文件夹里）； ③ 等 Actions 变绿后再刷新；④ 换手机流量或无痕窗口试试（国内访问 GitHub 偶尔慢/打不开，属正常）

❓ 常见问题（FAQ）

生成的网站里到底有哪些内容？

一个完整的宣传站：首页横幅（服务器名 + 一键复制地址 + 实时在线状态）、关于我们、服务器信息卡、6 大特色、三步加入教程、服务器规则、常见问题(FAQ)、一键加群按钮、页脚。手机电脑都适配。

这个向导页面本身就是我的宣传站吗？

不是。本页是生成工具。点上方按钮生成的 index.html 才是你的宣传站，把它部署到托管平台后得到的网址才是发给玩家的网址。

在线状态显示"离线 / 无法检测"，但我服务器明明开着？

状态检测走海外免费接口（已做双接口交叉验证，任一在线即显示在线）。部分国内公益服会被海外节点误报；若误报，刷新（有 60 秒缓存）或过一会儿再看，不影响玩家进服。

"一键加群"按钮点了没反应？

手机端需安装 QQ（点了直接跳群卡片申请）；电脑端会自动复制群号，去 QQ 搜索加群。填了官方加群链接后手机/电脑都直接跳官方加群页，最稳。

能"全自动签到 + 自动开服"吗？

不行，也不建议。公益开服平台的签到问答、先签到后开服，是平台反滥用的设计；绕过会封号甚至服务器被停。正确姿势：每天手动签到一次，配合下方"掉线提醒"，再也不怕忘开服。

双击生成的网页没反应 / 显示乱码？

用 Chrome 或 Edge 打开；文件保持 UTF-8 编码。千万别把 .js 当系统脚本双击运行（会弹"脚本宿主"错误，正常现象）。

以后想换自己的域名？

买个便宜域名（首年几块到十几块）绑到 Cloudflare Pages / GitHub Pages 即可，与本方案不冲突，详见各平台文档。

📡 可选完整功能：服务器掉线自动微信提醒

公益服经常自动停服 / 忘开服。开启后：GitHub 云端每 5 分钟检测一次，掉线自动推微信提醒你去开服，恢复也通知。需要 GitHub 账号，约 15 分钟。

  1. 打开本方案仓库 → 点 Use this template 生成你自己的仓库（会把哨兵文件 .watchdog、.github 一起带上）
  2. 把仓库里 .watchdog/check.sh 顶部 SERVER 改成你的服务器地址（顺手把两处"服务器名"改成你的）
  3. 拿 Server酱 SendKey：打开 sct.ftqq.com → 微信扫码登录并关注「Server酱」服务号 → 复制 SendKey
  4. 仓库 Settings → Secrets and variables → Actions → New repository secret：名称填 SERVERCHAN_KEY，值粘贴 SendKey
  5. 仓库 Actions 页 → 找到 server-watchdog → Enable / Run workflow 测试一次
  6. 以后每 5 分钟自动检测，掉线 / 恢复都会微信通知

💡 GitHub 定时任务可能有几分钟延迟，正常；超过 60 天无仓库活动会被暂停，去 Actions 页重新 Enable 即可。
